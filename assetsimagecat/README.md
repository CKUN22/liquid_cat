# 像素流体猫素材

`face.svg`、`blue_face.svg` 是原创逐像素五官，使用最近邻采样。身体通过粒子密度场逐像素生成，耳朵和尾巴按实时身体位置绘制，均由 `scripts/liquid_cat.gd` 构建。`white.tres`、`tabby.tres`、`orange.tres`、`blue.tres` 保存白猫、狸花猫、橘猫、蓝猫的配色，`cat_appearance.gd` 定义资源字段。狸花和橘猫的侧身条纹由粒子携带的初始材质坐标混合生成，随身体变形；额头和尾巴另有条纹。蓝猫采用蓝灰毛色及金色眼睛。

配色：毛色 `#fffdf2`、阴影 `#cbd5df`、轮廓 `#414458`、耳内 `#e9a6b2`。

角色场景：`scenes/liquid_cat.tscn`（白猫）、`tabby_cat.tscn`（狸花）、`orange_cat.tscn`（橘猫）、`blue_cat.tscn`（蓝猫）。

测试入口：`scenes/liquid_cat_lab.tscn` 提供全部 7 个房间；也可以直接打开 `water_cat_pool.tscn`、`cat_cascades.tscn`、`cat_funnel.tscn`、`water_cat_vessels.tscn` 按 F6 运行。水池和连通容器入口默认开启水状态；无需改动项目启动场景。

这是二维黏性流体角色原型，不是严格不可压缩流体。固定数量的等质量粒子、局部密度压力、成对黏性和弱内聚力共同维持身体；无固定身体轮廓。耳朵、脸和尾巴是维持辨识度的视觉层，不参与粒子密度或质量计算。极端薄缝中会保留最低限度的脸部显示面积。

## 操作

- A / D 或左右方向键：推动猫咪。
- W / 上方向键：毛团状态接地跳跃；水状态向上游动。
- S / 下方向键：毛团状态围绕质心压低身体；水状态向下游动。
- 空格：毛团状态接地跳跃；水状态施加局部冲量形成水花。
- 鼠标左键拖拽：施加有上限的外力，不直接传送身体。
- 按住 E：增强内聚力，帮助重新聚合。
- 1—7 或顶部按钮：斜坡台阶、窄道、压板容器、水池、阶梯瀑布、漏斗、连通容器。
- C 或毛色按钮：切换四种猫；F 或 WATER 按钮：切换水猫状态。切换时不重置位置、速度或粒子数量。
- P：切换往复压板，建议在容器场景落地后开启。
- V：查看粒子及质心；Tab：暂停物理；R：重置当前场景。

## 水猫状态

水猫降低黏性，关闭向质心的长程内聚力，并禁止拉力型负压力。它会在重力和局部密度压力下铺展、形成近似水平自由表面、流经漏斗和连通容器；空格冲量可激起波动，再自然回落。E 是明确的主动聚合操作，水状态也可使用，松开后恢复水的行为。水体有浅蓝色像素反光，保留猫脸、双耳和尾巴。状态切换不增加或移除物理粒子，仍是同一份流体质量。

这是低粒子数量的二维水行为近似，不是工程级不可压缩 SPH；允许水体分散成多个水团，特征层表示同一只猫。毛色标记混合会在极端流动时扩散，不是严格无扩散的纹理输运。

## 集成边界

第一版逻辑画布为 480 × 300；测试场在运行时设置窗口缩放，不改写 `project.godot`。猫咪节点保存粒子的画布坐标，保持节点原点不变。将顺时针（屏幕坐标）凸地形多边形传给 `obstacles` 即可参与自建的圆粒子碰撞，测试场绘制与碰撞使用同一份多边形。当前不自动读取 Godot 的 TileMap 或 CollisionShape2D，也不对其他刚体施加反作用力。

质心是等质量粒子位置的平均值。压力和黏性使用成对对称修正；内聚力扣除平均值，因此内部变形不会凭空推动质心。重力、地形接触和玩家输入属于外力，允许正常位移。`diagnostics()` 可读取粒子数、非有限值状态、固体内部粒子数及内部修正的最大质心误差。

本轮检查覆盖全部 7 种地形的毛团/水状态、水池铺展、水花恢复、切换时物理状态保留、WASD 动作绑定与上下游动的力方向；共记录 16 个物理结果。第一版另检查了持续压板和方向推力通过窄道。并不保证任意高速运动、无限细缝或任意凹多边形的稳定性。当前体积是近似维持，耳朵和尾巴也不是独立的物理流体。
