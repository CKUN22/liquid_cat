# 白色流体猫素材

`face.svg` 是原创逐像素五官，使用最近邻采样。白色身体通过粒子密度场逐像素生成，耳朵和尾巴按实时身体位置绘制，均由 `scripts/liquid_cat.gd` 构建，不拉伸整张猫咪贴图。

配色：毛色 `#fffdf2`、阴影 `#cbd5df`、轮廓 `#414458`、耳内 `#e9a6b2`。

场景：`scenes/liquid_cat.tscn`（猫咪），`scenes/liquid_cat_lab.tscn`（独立测试场）。打开测试场按 F6 运行；无需改动项目启动场景。

这是二维黏性流体角色原型，不是严格不可压缩流体。固定数量的等质量粒子、局部密度压力、成对黏性和弱内聚力共同维持身体；无固定身体轮廓。耳朵、脸和尾巴是维持辨识度的视觉层，不参与粒子密度或质量计算。极端薄缝中会保留最低限度的脸部显示面积。

## 操作

- 左右方向键：推动猫咪；空格：接地时跳跃。
- 鼠标左键拖拽：施加有上限的外力，不直接传送身体。
- 按住 E：增强内聚力，帮助重新聚合。
- 1 / 2 / 3 或顶部按钮：斜坡台阶、窄道、容器。
- P：切换往复压板，建议在容器场景落地后开启。
- D：查看粒子及质心；Tab：暂停物理；R：重置当前场景。

## 集成边界

第一版逻辑画布为 480 × 300；测试场在运行时设置窗口缩放，不改写 `project.godot`。猫咪节点保存粒子的画布坐标，保持节点原点不变。将顺时针（屏幕坐标）凸地形多边形传给 `obstacles` 即可参与自建的圆粒子碰撞，测试场绘制与碰撞使用同一份多边形。当前不自动读取 Godot 的 TileMap 或 CollisionShape2D，也不对其他刚体施加反作用力。

质心是等质量粒子位置的平均值。压力和黏性使用成对对称修正；内聚力扣除平均值，因此内部变形不会凭空推动质心。重力、地形接触和玩家输入属于外力，允许正常位移。`diagnostics()` 可读取粒子数、非有限值状态、固体内部粒子数及内部修正的最大质心误差。

测试覆盖三种静态地形、持续压板和方向推力通过窄道；并不保证任意高速运动、无限细缝或任意凹多边形的稳定性。当前体积是近似维持，耳朵和尾巴也不是独立的物理流体。
